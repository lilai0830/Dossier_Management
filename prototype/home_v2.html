Document Preparation Pipeline

Performance Dossier Management

A route to AI synthesis

1. Listen Folder

Set the Listen Folder (base directory where your projects live). New project folders dropped into it can be processed with one click — or automatically when Auto-Watch is on. The path is saved locally and reused next time.

2. Configuration

Optional. Tune the classification anchors and page-selection queries. Defaults work for most dossiers.

▶ Classification Config Click to edit classification anchors (classify/*.txt)

Classification frame: uses keywords from each document's first 1–2 pages to auto-sort it into CLINS / FE (Sensory) / CE.

▶ Page-Selection Config Click to edit page-selection queries (queries/*.txt)

Page-selection queries: at package time two parallel selectors run — keyword match picks on-topic summary pages, and layout structure (figures / lists / tables) picks information-dense pages — then both sets are merged for the downstream AI.

3. Run Pipeline

One click runs the whole pipeline for every project folder found in the Listen Folder: scan → classify → ingest → package. Finished PDFs are saved to <Listen Folder>/Dossier_condensed/.

Output D:\Projects\Dossiers\Dossier_condensed\
1Scan 2Classify 3Ingest 4Package 5Export

✓ Pipeline finished — synthesis PDF saved to Dossier_condensed\PROJ-001_synthesis.pdf

4. Auto-Watch

Watch Listen Folder OFF
When ON, the app monitors the Listen Folder. Any new project folder dropped in is picked up and the full pipeline runs automatically. Results go to Dossier_condensed/.
